# 学术界、产业界与未来方向

## 学术界成熟度

学术界已经在若干子问题上形成了清晰路线：

- 日志解析：Drain 等在线解析方法成熟，后续重点是变量感知、语义解析和日志演化。
- 日志异常检测：DeepLog、LogAnomaly、LogRobust 展示了从 LSTM 到语义鲁棒建模的演进。
- 指标异常检测：从 STL/统计阈值走向 SR-CNN、VAE、GAN、Transformer、GNN。
- RCA：从相关性排序、随机游走、拓扑传播，走向因果发现、图神经网络、知识图谱和多模态证据融合。
- LLM4AIOps：2023 之后快速增长，ACM Computing Surveys 2025 的综述统计了 2020-2024 年 183 篇相关论文，说明它已经成为独立研究热点。

学术界短板也很明显：公开数据集有限，真实事故标签稀缺；很多论文在固定 benchmark 上效果好，但不一定抗生产环境漂移；离线评估难以代表 MTTR、误导风险和组织协作效率。

## 产业界成熟度

产业界已经把 AIOps 嵌入真实生产系统：

- Microsoft：从硬件故障预测、事故管理、Narya，到 Azure Triangle System，多年持续投入。
- Meta：把 LLM 用于代码变更根因候选排序，强调闭环反馈和解释性。
- IBM：定义和推广 AIOps/observability，并有 CloudRanger 等研究。
- 云厂商和工具厂商：Dynatrace、Datadog、Splunk、Grafana 等把 AIOps 融入可观测性平台。
- CNCF/OpenTelemetry：推动指标、日志、链路等遥测数据标准化，是 AIOps 数据底座的重要方向。

产业界核心矛盾不是“有没有模型”，而是：

1. 数据是否完整、可信、可追溯。
2. 模型是否能融入值班流程。
3. 推荐是否可解释、可验证。
4. 自动化动作是否有权限边界和回滚能力。
5. 效果是否能用 MTTA、MTTD、MTTR、TTM、误报率、转派率、人工节省时间衡量。

## 制造业成熟度

制造业的算法研究很热，但产业落地更加分层：

- 单设备预测性维护较成熟：振动、温度、电流、压力等传感器数据建模。
- 产线级异常检测正在发展：需要把设备、工位、节拍、质量和人工操作结合。
- 跨工厂模型迁移仍难：设备型号、工艺路线、供应商、班组、环境差异都会造成漂移。
- 数字孪生和标准化在推进：ISO 23247、NIST 等在提供共同语言。
- 生成式 AI 刚起步：主要用于知识问答、维修辅助、文档生成、低代码分析，不宜直接闭环控制设备。

## 未来方向

### 1. 从相关性到因果性

当前很多 RCA 方法本质是“相关性排序”。未来更需要把拓扑、时间先后、变更、干预、专家知识结合，判断“如果修复这个节点，事故是否会缓解”。因果图、结构因果模型、反事实评估会越来越重要。

### 2. 从单模态到多模态

真实事故很少只靠一类数据定位。未来系统会同时使用：

- 指标曲线。
- 日志文本。
- Trace 拓扑。
- 代码 diff。
- 配置变更。
- 工单/IM 对话。
- Runbook。
- 工业场景里的传感器、图像、质检结果、维修记录。

LLM 的价值不在替代所有模型，而在做语义对齐、证据编排、工具调用和报告生成。

### 3. 从 Copilot 到受控 Autopilot

短期内 Copilot 是主流：给候选根因、建议动作、自动摘要，由人批准。中长期会出现受控 Autopilot：低风险动作自动执行，高风险动作走审批，所有动作可审计可回滚。

### 4. Agent 可观测性

如果未来 SRE-Copilot 本身由多 Agent 构成，那么 Agent 系统也要被运维：

- 哪个工具调用失败。
- 哪一步推理产生错误。
- 哪个知识源过期。
- 哪个 Agent 延迟高或成本高。
- 是否越权调用。
- 输出是否被人工采纳。

这会形成 AgentOps 与 AIOps 的融合。

### 5. AIOps for AI Infrastructure

大模型训练、推理、数据闭环、仿真平台、标注系统都会成为智能汽车公司的核心生产系统。AIOps 未来要保障的不只是 Web 服务，还包括 GPU 集群、数据管道、模型服务、向量库、RAG、评测平台和仿真系统。

### 6. 工业 AIOps 与数字孪生结合

在制造业，数字孪生可以为 AIOps 提供“系统结构”和“物理约束”。单纯黑盒模型很难解释为什么某个工艺参数导致质量异常，而数字孪生 + 知识图谱 + 时序模型可以把诊断结果映射到设备、工艺和质量语言。

## 你应该建立的前瞻性观点

1. 数据底座比模型更稀缺。谁能把运维数据、工业数据和知识库治理好，谁就有长期优势。
2. LLM 是编排层和语义层，不是所有检测问题的银弹。
3. 工业场景最缺的是可解释、可迁移、可落地的系统，不是离线指标最高的模型。
4. 自动化必须受 SLO、权限、风险等级、回滚策略约束。
5. AIOps 的终局是“可靠性操作系统”：感知、诊断、计划、执行、学习形成闭环。
